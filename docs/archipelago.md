# Tide archipelago

Seven differently sized, rotated, scalloped islands surround the existing mainland: Pinewatch, Birch Sound, Sunspine, Palm Cove, Blossom Reach, Autumn Ridge and Acacia Key. Each has sandy shores, broad grassy terraces and an off-centre hill/mountain. The mainland gains a stronger north-west ridge and peak. All relief uses the existing 20 sculptable terrain layers; one-layer climbing and the 0.58 world-unit editing grid remain intact.

Shallow submerged shelves connect the islands to the mainland. Players can raise these into dry causeways; water crossings are not automatically walkable. Surf adapts to all coastlines. The overview camera now frames the wider archipelago.

Trees share Tide's faceted geometry and wind animation. Regional forms include layered pines, pale-trunk birches, branching acacias with flat crowns, palm fans, blossom and autumn crowns. Mainland groves also include narrow cypress silhouettes and occasional decorative fruit trees. Trees remain scenery alongside existing harvestable resource nodes; decorative fruit does not create food.

Save version 9 upgrades existing terrain once. Only samples still matching the previous mainland generator are eligible, with additional buffers around sculpting, villages, buildings, orders, resources, animals, traps, trails, current work routes and fishing waters. Existing food, animal counts and job data are retained. Startup saves the previous raw island to a before-archipelago backup. Existing developed or heavily sculpted areas can retain their former relief; a new archipelago gives the complete default geography. Once upgraded, saved terrain is authoritative and newly sculpted changes are never regenerated. Older save formats remain accepted.

Validation includes separate dry-land components, beaches and highland terrain on each island, old-save migration, preservation of inhabited/sculpted land and repeated save restoration, plus the settlement, food, terrain and navigation regression suites. No browser visual or device-performance testing was requested.
